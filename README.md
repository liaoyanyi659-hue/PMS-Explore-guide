# PMS 校园探索 — GitHub Pages 发布版

包含当前网站全部 HTML、CSS、JavaScript、照片及地图。

## 发布步骤
1. 解压 ZIP。
2. 创建 Public GitHub 仓库，例如 pms-campus-guide。
3. 上传解压后的所有文件与 photos 文件夹，保持目录结构。
4. 确保 index.html 直接位于仓库根目录，不要只上传 ZIP。
5. 仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。
6. 发布完成后，打开 Pages 页面显示的网址。

网站是静态网页，无需数据库、npm 安装或构建。
.nojekyll 是供 GitHub Pages 使用的空文件。
在线地图和校外系统链接需要网络；网站可下载文字离线指南。
以后修改文件并提交到同一分支即可更新；与 ChatGPT Sites 版本不会自动同步。
