First-time setup

Import the existing guide once to start editing places. Existing database entries are kept.

Account editor

Suspend an account to block access while retaining its posts. Your own administrator access is protected.

Page content blocks

Add a text block to a section, or replace a supported section with a published block. Drafts stay private. Editing the website layout still requires code changes.

Upload a photo

JPG, PNG or WebP · maximum 4 MB and 6 million pixels. Uploaded photos are resized and re-encoded. Choose a photo in the place or page editor to use it.

Bundled photos remain in GitHub / photos. Their paths can be selected in the place editor; this library manages newly uploaded photos.

Pending reports

Account, content and photo changes are recorded without passwords. Announcement and forum moderation actions are also recorded when logging is available.

Content editor

Existing identifiers are fixed so links and map references keep working.
